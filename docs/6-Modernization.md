# 第6問：開発環境のモダナイゼーション

下記要件を満たす `Pull Request` を `featureブランチ` として作成してください。

## 課題背景

現在のプロジェクトは構成が古く、開発体験（DX）やメンテナンス性に課題があります。  
これ以降の課題（コンポーネント設計やアルゴリズム実装）を効率的かつ高品質に進めるための基盤として、  
ビルドツール、テスト、静的解析のすべてを最新の技術スタックへ刷新してください。

## 要件

### 1. Vite への完全移行

既存の `Webpack` 環境を廃止し、`Vite` でアプリケーションが動作するようにしてください。

### 2. ESLint の導入

- 最新系の`ESLint`を導入し、ベストプラクティスに基づく設定を行ってください。
- `npm run lint`でリントが実行され、エラーが検出・修正できる状態にしてください
- Visual Studio Codeでリントが実行され、エラーが検出できる状態にしてください

### 3. Prettier の導入

- 最新系の`Prettier`を導入し、ベストプラクティスに基づく設定を行ってください
- ESLintと連携を行ってください

### 3. Vitest の導入

- `Vite` 環境上で動作するユニットテスト環境を構築してください。
- これ以降の課題でテストコードを記述するために必須となります。
- `npm run test` でテストが実行されるようにしてください。

### 4. テストファイルの作成

- 既存コンポーネントも含め、テストファイルを作成し、パスさせてください。
