# 第1問：GitとGitHub

下記要件を満たす`Pull Request`を `featureブランチ` として作成してください。

## 要件

1. 下記のマニュアルを`Markdown`ファイルとして作成して、`manual`ディレクトリに格納してください
2. 作成したファイルを `署名付きコミット` し、`feature` ブランチとして、`適切なブランチ` に `Pull Request` を作成してください。

### 作成するマニュアル

- `ed25519` 形式の`sshキー` を作成する方法
- `git-flow` のローカル設定の方法
- `GitHub` への `sshキー` の登録を行う方法
- `ed25519` 形式の `GPGキー` を作成する方法
- `GitHub` への `GPGキー` の登録を行う方法
