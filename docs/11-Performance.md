# 第11問：パフォーマンス最適化

下記要件を満たす `Pull Request` を `featureブランチ` として作成してください。

## 課題

第五問で実装した「Hacker News」リストについて、要件が変更されました
**「過去のニュースも含めて `10,000件以上` をページネーションなしでシームレスに閲覧したい」**との事です。

## 要件

- リスト内の各ニュース記事の表示には、**第七問で作成した「汎用カードコンポーネント」を使用してください。**
  - カードの `Slot` や `Props` を活用し、ニュースのタイトル、投稿者、日付などが適切に表示されるように組み込んでください。
- 10,000件のデータがあってもDOM描画コストを一定に保てるよう、仮想スクロール（ウィンドウ内のみレンダリングする手法）を実装してください。
   - ライブラリを使用しても、自前で実装しても構いません。
- 10,000件の記事詳細（タイトル等）を一度にすべて取得するのではなく、**「表示に必要な分だけ」**
  - あるいは **「スクロールに合わせて順次」** 取得する仕組みを実装してください。
  - ユーザーがスクロールするまで、画面外のはるか下にあるデータの通信を行わないように制御してください。
- リストをスクロールした状態でブラウザを**リロード（再読み込み）**した際、リロード前と同じスクロール位置が表示されるようにしてください。
- `Chrome DevTools` や `Lighthouse` を使用し、実装後のパフォーマンス（FPSやメモリ使用量）が良好であることを確認してください。
