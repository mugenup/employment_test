# 第7問：デザインシステムと汎用コンポーネント設計

下記要件を満たす `Pull Request` を `featureブランチ` として作成してください。

## 課題背景

第6問で導入した環境（Vite/SCSS等）を活用して実装してください。

## 要件

- チーム開発で再利用可能な「汎用カードコンポーネント（`BaseCard.vue`）」を作成してください
- カードの「ヘッダー」「メディア（画像等）」「本文」「アクション（ボタン等）」など、中身を柔軟に変更できるよう `Named Slots`（名前付きスロット）を実装してください
- `props` を通じて、カードの見た目を以下の3パターンに切り替えられるようにしてください。
  - `elevated`: 影付き（デフォルト）
  - `outlined`: 枠線のみ
  - `flat`: 背景色のみ（枠線・影なし）
- スマートフォン表示とPC表示でレイアウトが適切に切り替わるようにCSS（またはSCSS）を記述してください。
