# 第9問：ロジックの抽象化とカスタムフック

下記要件を満たす `Pull Request` を `featureブランチ` として作成してください。

## 課題

現在、コンポーネント内に散らばっているデータ取得（Fetch）のロジックを整理し、再利用可能な形にリファクタリングしてください。

## 要件

- データ取得ロジックを `useFetch` のような汎用的な `Composable` 関数（カスタムフック）として切り出してください。
  - この関数は、以下のリアクティブな状態を返却するようにしてください。
    - `data`: 取得したデータ
    - `error`: エラー情報
    - `isLoading`: ローディング中かどうか
- 同じURLに対して短期間に何度もリクエストが飛ばないよう、簡易的なキャッシュ機能（メモリ内キャッシュで可）を `useFetch` 内部に実装してください。
- コードの堅牢性を高めるため、JSDoc等を用いて型推論が効くように記述してください。
  - 可能であれば、レスポンスの型をジェネリクス等で指定できる設計にしてください。
