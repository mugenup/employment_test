# 第10問：アクセシビリティ(A11y)の向上

下記要件を満たす `Pull Request` を `featureブランチ` として作成してください。

## 課題

第三問で作成した「ダークモード切替スイッチ」および第四問の「ソーシャルアイコン」について、  
すべてのユーザー（スクリーンリーダー利用者やキーボード操作のみのユーザー）が利用できるように改善してください。

## 要件

- クリック可能な要素には適切なタグ（`<button>` や `<a>`）を使用してください。
- アイコンのみのボタンには、視覚的には見えなくてもスクリーンリーダーが読み上げるラベル（`aria-label` 等）を付与してください。
- トグルボタンには現在の状態（ON/OFF）を示す `aria-pressed` 属性等を適切に設定してください。
- マウスを使わず、`Tab` キーと `Enter/Space` キーのみですべての操作が完了することを確認してください。
- フォーカス時（`:focus-visible`）に、どの要素を選択しているかが視覚的にわかるスタイルを適用してください。
