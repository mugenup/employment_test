# frontend-hiring-challenge

このプロジェクトは、Vue 3とwebpackを使った開発を始めるためのものです。

## 設定のカスタマイズ

webpack.config.jsを参照してください。

## プロジェクトのセットアップ

```sh
npm install
```

### 開発用のコンパイルとホットリロード

```sh
npm run dev
```

### 本番用のコンパイルとミニファイ

```sh
npm run build
```

### [ESLint](https://eslint.org/)でのLint

```sh
npm run lint
```

### フォーマット

```sh
npm run format
```
